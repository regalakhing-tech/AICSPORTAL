# AGENT.md

## Project Overview
This project is a **Web-Based AICS Beneficiary and Distribution Notification System** developed for the **Provincial Social Welfare and Development Office (PSWDO)**. It is designed to manage beneficiary profiling, request processing, validation, prioritization, SMS notification, reporting, and monitoring for the **Assistance to Individuals in Crisis Situation (AICS)** program.

## Tech Stack
The project uses the following technologies:

- **Backend:** PHP
- **Frontend:** JavaScript
- **Markup:** HTML5
- **Styling:** CSS
- **Framework:** Bootstrap
- **Database:** MySQL
- **Local Server Environment:** XAMPP
- **Code Editor:** Visual Studio Code

## Development Environment
This system is developed and tested in a local environment using **XAMPP**. XAMPP provides:

- **Apache** for running the PHP web application
- **MySQL** for database management
- **phpMyAdmin** for database administration

## Database Configuration
- **Database Name:** `AICSdb`

Make sure the database is created in MySQL before running the project.
